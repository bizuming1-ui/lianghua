## AI 决策的第一性原理

LLM 不能凭空预测价格。**数学做裁判、LLM 做分析师**:

1. `quant_math.py`:EWMA/ATR 波动率、方差比、岭回归 + 70/30 时间切分(含 embargo)样本外检验。
2. `indicators.py`:全部指标 + 样本外 IC 学习复合分。
3. `ai_engine.py`:隔夜联动(159502 ← XBI)、宏观、新闻 → 提示词(含历史教训、自适应状态)→ 2~3 次独立推理投票 → JSON。
4. **数学闸门**(代码执行,LLM 不能越过):多次采样一致、校准后置信度、非冷静期、真实行情源、连续竞价、避开开收盘、价格未漂移、样本外统计优势、学习复合分不反对、规则投票不极端看空、资金≥一手、**预期净优势≥ k×往返成本(含固定 ¥5 手续费)**、上涨概率≥52%、24h 亏损≤3% 本金、不加仓、5 分钟冷却、凯利期望为正。
5. 持仓由代码执行止损/止盈/到期/收盘前平仓;所有决策到期后自动复盘。

### 关于固定 ¥5 手续费的数学事实

本金 ¥10,000、一次往返 ¥10 = 约 10bp(满仓)——名义金额越小越贵(¥2,000 的往返手续费就是 50bp)。所以:仓位由"单笔风险预算 1.5% ÷ 止损幅度"决定(通常接近满仓),而不是 1/4 凯利(小仓位会被固定手续费吃光);并且预期净优势必须显著大于成本。**这意味着系统会很少交易** —— 这是正确的,不是 bug。

## 诚实的边界

* 这是**模拟盘**,不构成投资建议。行情来自公开免费接口,可能有延迟;休市时价格不变(日志备注"休市·按最近价成交")。
* "毫秒级刷新"指**抓取与推送频率**(0.5 秒抓取、200ms 推送、前端即时重绘);报价本身多久变一次取决于交易所与数据商(免费源通常数秒一次),系统不可能比数据源更快。
* **没有任何模型能保证胜率。** 提升来自"选择性":没有样本外统计优势就不交易;反思与自适应只会让系统更谨慎、更聚焦。真实的 K 线上,多数指标样本外并不显著(本系统会如实显示"样本外不可靠"),真正可验证的优势主要来自**隔夜联动**(159502 跟随前一美股交易日 XBI)与少数极端状态。
* "双卡一直工作"= 只要大模型在线,推理循环就不停(张量并行下任何一次生成两张卡同时计算);不代表一直在交易。占空比会实时显示。
* Kaggle 会话关闭后服务随之停止;不配置 `GITHUB_TOKEN` 时数据只在本会话/本地文件有效(页面会明确提示)。
